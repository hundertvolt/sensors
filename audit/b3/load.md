# Resource × level load cells (A.U35.28, OR49.a (3))

Requirement: one cell per resource × level with its load, limit, degradation and recovery (A.U35.28 (1)), and the OR49.a (3) entries the lanes relay. Completion: every cell measured or justified. A defect any file records goes the OR12.a path (fixed with a regression test seen failing first, or an owner question), never a note alone, and passes A-C as a delta before it is applied (OR106.a). The file is complete when every row is terminal: biting, fixed, or justified with its reason. Opened by A.U35.01 / M.PROC.022 (agent, 2026-10-22); deleted with `audit/` at phase D.

## The pass condition and how a cell is read (LD+CM3, agent, 2026-10-28)

G4/R65's pass condition, split into the letters the cells use: **d** the degradation at the limit is asserted (the refusal, drop, fallback or clamp, not only survival); **r** a checked return to baseline once the load stops (the resource's own count back where it was, and the service doing its normal work again); **m** no `MemoryError` / "memory allocation failed" marker; **f** no log flood (the entries the load writes are bounded: an exact count, one history slot per repeated code under OR35.b's newest-entry rule, or a chunk-write bound); **c** no crash, reboot or watchdog reset. No load test writes the flash filesystem or the SCD30's NVM (OR49.a (2)); FRAM writes are not wear. A letter in capitals is asserted by the test itself; one in lower case comes from its tier's own check, named here once:

- L1/L2 `tests/test_*.py`: **m** `scripts/test.sh`'s per-file memory gate; **c** a crash ends the file without its summary line; **r (tasks)** `tests/microtest.py`'s `_drain_scheduler()` fails any test that leaves a task parked.
- L2 scenarios (`scripts/_digital_twin_scenarios.py`): **m** `Context.check_log()` on every boot's log; **c** the clean SIGINT shutdown, "ended on its own" and the feed-gap verdict of every boot; a shared scenario's idle check adds **r** (every slot free, the accept queue empty) and **f** (no error count moved but those it states).
- L2 CI suite runs (`scripts/_digital_twin_ci_suite.py`): **m c** `_check_run_log()` on every launch.
- L4 bench: **f** and, for anything the firmware logs, **m** the autouse `no_unprovoked_log_entry` (`tests_hardware/bench/conftest.py`): an E or W entry outside the test's `provokes_log` set fails it, a caught allocation failure included; a console-only marker is read only where the test greps `crash_lines()` / `MEMORY_ERROR_MARKERS`.
- L3 flash: no tier-wide log or marker check yet (the CRr2 lane's flash-tier `logs` fact); a cell's **m f** are the test's own.

State: **complete** (the test asserts every letter that applies), **strengthened** (it asserted part; the missing letters were added here, each seen failing first on a plant the unchanged test passes), **new** (a gap, filled here), **justified** (no load of this resource exists at this level, with the reason), **owed** (the cell's silicon run, a `queue_c.md` row), **named** (the missing letter lies in another lane's file, named in the LD+CM3 hand-back). Plants are in `S/u35/laneB/ldcm3/plant*`; none is committed.
