speed and footprint (OR16, OR19, OR21, OR22, OR23, OR25, OR37-OR41, OR49). B3 runs after B2 (U10-U34), so it finds the

**Standing constraints applied to every action** (CLAUDE.md, owner rows):
- Levels (OR45.a): U35's own actions are L0-L2 plus the L3/L4 preparation. Nothing touches the board or the bench host:
  every action of Kind `hardware` names the phase-C round it joins (each round needs the owner's go-ahead in its own
  conversation, CLAUDE.md), and runs its instrument in the twin first (LEAD/R01, A.U26.05).
- GC stages (OR40.a (2)): every MicroPython-running level runs at the reactive default `-1` and again at
  `GC_THRESHOLD=32768`, each pass on its own with zero `MemoryError`/`memory allocation failed` in any output (the four
  gates, CLAUDE.md); no `gc.collect()` added except a measurement baseline (OR39.a (1), OR55.a).
- Sensitivity proofs (OR21.a (2); harmonization 5, 18): every planted fault lives in a throwaway worktree, its scripts
  in `audit/sweeps/` only, deleted at close; no new permanent control arm; existing ones stay.
- Determinism (OR37.a (2)-(3)): a race is proven by a forced interleaving; a bounded repeat (≤ 20 runs, tmpfs) only
  confirms. Wear (CLAUDE.md, OR49.a (2)): load writes no limited-endurance store; an owned persisting write is gated.
- Working files (harmonization 19; OR25.a (4), OR41.a, OR45.a (4), OR11.a): the review ledger, the fault record, the
  intent map, the two matrices, the file × level matrix, the load table, the measurement record, the E.5.1 verdict
  table and the raising-call map live under `audit/b3/`, deleted with `audit/`; what outlives them is tests and
  permanent text.
- Permanent text an action writes carries no audit ID (brief rule 6); provenance is "(owner, <date>)" /
  "(agent, <date>)"; `[src: …]` notes are never written. Device sets are derived, never named (OR78.a).
- Recovery ladder (brief rule 8, OR113.a (2)): U35 owns no product fault path of its own; A.U35.52 checks that every
  rung the earlier units planned is tested at every level that can reach it.
