  line of the input at its line number (comments included; `mpy-cross` drops comments), so a field traceback's line
  numbers equal `src/`'s; with no `ast.unparse` the result depends only on the source text and the AST positions,
  which do not vary with the host CPython or its hash seed. A file with no match is returned unchanged (identity, as
