### A.U10.02 Add the measured-seconds primitive `TickSeconds`
- **Why**: REF/R03 — "One SPEC G.2 primitive in `src/base_classes.py`, next to `LockedCounter`, accumulates the
  deltas into whole seconds plus a millisecond remainder, counts up or down and saturates at 2**30 − 1 s, checked
  before the step … code in U10 — the primitive and its G.2 entry" (owner, 2026-09-29, OR101.a, OR104 "the 'never
  UTC' goes for the others as well", home `base_classes.py` (agent, 2026-09-29), OR104.a (3)); K.40.
- **Site**: `src/base_classes.py` after `LockedCounter` (`:117`); new `import time`.
- **Change**: `class TickSeconds` (sync; no lock: no method awaits, so no other task runs between its reads and
  writes — stated at the class): `__init__(self, *, count_down: bool = False)` sets `_down`, `_value = 0`,
  `_rem_ms = 0`, `_last = time.ticks_ms()`; `restart(self, value_s: int = 0) -> None` sets `_value =
  min(max(value_s, 0), COUNTER_CAP)`, `_rem_ms = 0`, `_last = time.ticks_ms()`; `read(self) -> int`: `now =
  time.ticks_ms()`, `delta = time.ticks_diff(now, self._last)`, `self._last = now`; if `delta > 0`: `ms =
  self._rem_ms + delta`, `secs = ms // 1000`, `self._rem_ms = ms - secs * 1000`; counting down `self._value =
  self._value - secs if self._value > secs else 0`; counting up `self._value = self._value + secs if self._value <
  COUNTER_CAP - secs else COUNTER_CAP`; returns `self._value`. Header comment: "a caller reads it at least once per
  2**29 ms (6.2 days, `ticks_diff()`'s horizon); a negative delta (never on target within that horizon) is ignored".
