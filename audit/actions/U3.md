# A-L U3 — central log-repeat rule and one entry per event (HEAD 04efc1f)

Built together with U2: the numbers named here (`_ERR_…`/`_WRN_…`, values) are A.U2.01's catalog. One rule decides
every pair below (agent, 2026-09-29, read from OR56.a (1) and G3/R02's own resolution, where the driver that detects the
read failure keeps its errno 11 and the base class that learns of it prints): **the layer that detects a fault persists
it; a layer that only learns of it from a callee's failure return prints it (`pr.err()`/`pr.wrn()`)**. A layer that
detects a *new* condition from that failure (a give-up, a task end, a drain bound) persists that condition as its own
later event.
