# A-L U6 — One-source website definitions (HEAD 04efc1f)

Scope: the chain `src/` `# @web`/`# @web-group` tags → `buildgen/web_tag.py` (grammar) →
`buildgen/definitions.py` (`generate_definitions()`, generator-owned catalogs) → build output
(`scripts/_generate_sensortask_modules.py`, `scripts/build_website.sh`) → `js/definitions.js`
(`validateDefinitions()`, typedefs) → `js/render.js`/`templates.js`/`mock-server.js`/`app.js`/`main.js` →
`tests_js/`, `tests_scripts/`, `scripts/cross_browser_smoke.mjs`. Every site below was opened at
HEAD 04efc1f. Earlier-unit action files: none existed in `audit/actions/` when this file was written
(wave 1 runs U0-U8 in parallel), so U2/U4 dependencies are cited by register ID, not action ID.

Paths this file introduces (used by several actions, defined once here):
- `build/generated_src/definitions/<device>.json` — every device's generated definitions (A.U6.02).
- `build/generated_src/definitions/index.json` — `{"devices": [<sorted ids>]}` manifest (A.U6.02).

- `mockdata/samples.json` — driver-keyed mock sample table replacing `mockdata/wozi.json`/`dev.json` (A.U6.06).
- `tests_js/_generated_definitions.js` — the one tests_js loader for generated definitions (A.U6.05).
