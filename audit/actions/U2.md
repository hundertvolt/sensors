# A-L U2 — error-number catalog (HEAD 04efc1f)

Code at HEAD 04efc1f is identical to `821bda8` (the only later commit touches `audit/CONSOLIDATION.md`); line
numbers below are read at that tree. Units U2 and U3 were built together: which member of an error+warning pair
stays persisted is U3's decision (A.U3.03-A.U3.09, rule "the layer that detects a fault persists it, a layer that only
learns of it from a callee's failure return prints it"); this catalog allocates numbers only for the entries that stay
persisted after U3. A number that U3 turns into a console print is listed as "not allocated (A.U3.nn)".

- **Why**: G5/R19 — "enforced by a test over every call site"; OR28.a (3) "A test reads every `err_s`/`wrn_s` call in

  (6) no `_ERR_`/`_WRN_`-prefixed constant in `src/` holds anything but a catalog code (bmp3xx `_ERR_CMD` renamed,

### A.U2.04 One idiom: named `_ERR_`/`_WRN_` constants per module
- **Why**: G10/R18 — every code by keyword, "written one way project-wide — a literal checked against the C.7.1
  catalog or a named constant with one prefix — chosen with the OR28 catalog"; "a constant that is not an error number
  carries no errno prefix". Decided here: named `const()` constants, because UART codes also travel as return statuses
  (`asy_uart_comm.py:242-250` `_init_errno`, `:448-493` frame checks, `:648` `err == _ERR_WRONG_KIND`), which a bare
  literal would turn into magic-number comparisons; an underscore-prefixed `const()` emits no code and no global
  (v1.29.0 `py/parse.c:855-861`), so the idiom is free on the board (agent, 2026-09-29).
- **Site**: every `src/` module in A.U2.05-A.U2.20; `src/api_response.py:34`; `src/asy_fram_manager.py:38`.
