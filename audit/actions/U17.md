- **Why**: G3/R21 — "the six UART entry points take one order, readiness gate then argument checks; today
  `uart_get_into()`/`uart_get_stream()` check arguments first … and the SET forms gate first … OR24.a (1) consistency,

  delegates to `uart_set_into()` and inherits its order.)

  its `push is None` check (`_ERR_BAD_ARG`), then `_run_get(...)`; (3) `uart_set_stream()`: the `pull is None` check
  (`:845-850`) moves above `_check_size(total_size, …)` and the `bus is None` check (`:840-842`) moves below both.
  `uart_set_into()` is already in this order. No awaited call that can suspend on the success path sits between
  `_gate()`'s `_busy` test and `self._busy = True` (every `_check_*` awaits only on its refusal path) — kept so; one
  comment line above `_run_get()`: "# Shared tail of the three GET forms: each gates, then checks its own arguments,

### A.U17.02 Pin the general-purpose initiator API with contract tests
- **Why**: G3/R21 — "`asy_uart_comm.py`'s `uart_set`/`uart_set_into`/`uart_set_stream`/`uart_get_into`/
  `uart_get_stream` (:808-888) stay as general-purpose API with contract tests, no product caller needed (owner,

- **Site**: `tests/test_asy_uart_comm.py`, new section after `:1336` (`test_a_streamed_total_size_must_be_declared`),
  header comment "# ---- General-purpose initiator API: no product caller; kept as the standalone module's API
  (owner, 2026-09-29) ----".
- **Change**: contracts already pinned at HEAD (kept, listed so the section header names them): identical bytes for
  `uart_set()`/`uart_set_into()` and `uart_get()`/`uart_get_into()` `:1228-1245`; too-small `_into` destination
  `:1248-1252`; `None` destination `:1255-1260`; pull stream `:1263-1289`; push stream `:1292-1301`; short-filled and
  wrong-shaped pull `:1305-1322`; push refusing a chunk `:1325-1330`; undeclared stream size `:1333-1336`; argument
  refusals `:1353, 1365, 1390, 1430-1434, 1443, 1451, 1614-1615`; mid-train pull aborts `:2005-2040`. New tests, each
  against J.9 as the independent source: (1) `uart_get_into()` of a genuinely empty answer (`echo_get(b"")`) returns
  `0`, never `None`, and leaves the destination untouched; (2) `uart_get_stream()` of an empty answer returns `0`;
  (3) `uart_get_into(id, buf, exp_size=5)` against a 4-byte answer returns `None` (size mismatch, refused before the
  final ACK: the initiator's wire carries no ACK for the answer's last chunk, J.4) and `exp_size=0` against an empty answer returns `0`;
  (4) `uart_set_into(id, None)` and `uart_set_into(id, bytearray(4), 0)` each return `True` and the responder's
  `ListenResult` is `(id, CMD_SET, None)` (J.9: an empty payload is delivered as a distinct outcome); (5)
  `uart_set_stream(id, 0, pull)` returns `True`, sends a two-chunk train whose second chunk has `SIZE = 0` (initiator
  wire, J.4), and calls `pull` once with a zero-length region; (6) `uart_set_stream()` with `total_size =
  254 × PAYLOAD_SIZE` completes a 255-frame train with the bytes intact, and `254 × PAYLOAD_SIZE + 1` returns `False`
  with an empty initiator wire (refused before the first frame, J.4's `CHUNKS ≤ 0xFF`); (7) buffer borrowed for the
  call only (J.9 via B9): after `uart_get_into(id, dest)` returns, a second GET into a different buffer leaves `dest`
  byte-for-byte unchanged, and after `uart_set_into(id, src, n)` returns, mutating `src` changes no later frame on the
