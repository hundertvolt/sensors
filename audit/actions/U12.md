### A.U12.01 Compute CRC32 inside rp2 small ints

- **Change**: `__init__` (after `self.poly` is set, `:24`) gains the two-word constants, zero unless the register is
  wider than 16 bits and a polynomial is set: `wide = self.poly is not None and self.num_bytes > 2`;
  `hi_bits = self.num_bytes * 8 - 16`; `self._hi_mask = (1 << hi_bits) - 1 if wide else 0`;
  `self._hi_msb = 1 << (hi_bits - 1) if wide else 0`; `self._hi_shift = hi_bits - 8 if wide else 0`;
  `self._poly_hi = self.poly >> 16 if wide else 0`; `self._poly_lo = self.poly & 0xFFFF if wide else 0`, with the

  bits keep today's loop, whose largest intermediate is 0x1FFFF). New `async def _crc_wide(self, buf, crc) -> int`:
