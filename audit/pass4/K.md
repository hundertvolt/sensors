Method: an AST pass (`scratchpad/pass4/K/scan.py`: every `+=`/`-=`/`*=`/`<<=`, every `x = x ± …`, every

Platform facts used throughout (v1.29.0 source): rp2 builds `MICROPY_OBJ_REPR_A` (default,
`py/mpconfig.h:162-163`) with `MICROPY_LONGINT_IMPL_MPZ` (`ports/rp2/mpconfigport.h:127`), so
`MP_SMALL_INT_MAX` = 2**30 − 1 = 1,073,741,823 (`py/smallint.h:37-42, 62`). A small-int `+`/`-` whose
result leaves that range becomes a heap mpz (`py/runtime.c:595-599`); any arithmetic or bitwise op with
an mpz operand allocates a fresh mpz result (`py/objint_mpz.c:214-215`, ops `>= MP_BINARY_OP_INPLACE_OR`,
`py/runtime0.h:106-134`), while a comparison with an mpz does not (`py/objint_mpz.c:319-320`). A
big-int `const()` is folded as a constant object (`py/parse.c:369-385, 842-850`). rp2's epoch is 1970
(`ports/rp2/mpconfigport.h:147`), so every current UTC timestamp (≈1.79e9) is already an mpz. The L1/L2
Unix port (standard variant, 64-bit word, REPR_A) has `MP_SMALL_INT_MAX` = 2**62 − 1
(`py/mpconfig.h:2308` with `py/smallint.h:37-42`): it cannot observe rp2's 2**30 boundary. Rates use
2**30 s = 34.0 years, 2**30 at 2/s = 17.0 years, 2**30 at 217/s (G9/R09's 115200-baud frame maximum) =
57.3 days.
