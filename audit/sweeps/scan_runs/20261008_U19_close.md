# U19 close scan (silent_failure_scan.md), 2026-10-08

Unit U19: the webserver service, the response envelope, the config manager's result words, the setter/lock layer's
config GET, the generated routes and status keys, the website mock and samples, and the per-device REST reference. The
webserver guards every request head before Microdot parses it, counts every dropped connection in a 24-hour window
(`HTTPDropped`, cleared by `ResetErrors`), traces each drop once, rebinds Microdot's exception print to the level-gated
logger, retries a failed server start, serves static files from one held stream and answers an unknown key, sensor or
malformed entry "Invalid". A config GET runs under the module's write lock and answers `{"error": "unavailable"}` when
its source cannot be read; the result words are four shared constants a scan pins; a generated `api/<device>.json`
states every route's fields. Eleven lanes on disjoint files; the lead merged them, fixed what the merge made red, shrank
the allow-lists and recalibrated the serving-demand budget.
