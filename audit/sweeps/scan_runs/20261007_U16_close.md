# U16 close scan (silent_failure_scan.md), 2026-10-07

Unit U16: FRAM storage. The driver reads the chip ID up to three times, checks it against the declared size, and
reports partial write protection; a write-latch anomaly probes the ID (at once when the status byte is impossible)
and a lost chip persists E54. The manager seeds every chunk's CRC with its owner's name, so a shifted or foreign
layout reads blank or invalid instead of restoring a neighbour's history; its read is tri-state (valid, blank or
invalid, unreadable), a fault keeps the stored bytes, and a watch task escalates a dead chip through the supervisor
like any declared chip. The log store merges what was logged before `setup()`, never overwrites an unreadable store,
writes back only when the merge changed the ring, and persists `LOG_RAM_ONLY` when it runs RAM-only. The allocator's
refusal records nothing (owner, 2026-09-16). SGP40 gives its backup an owner, restores tri-state, and keeps its live
state across a task restart. The generated collectors include FRAM's starters; a new hold-timing device script; the
docs follow the code. Seven lanes on disjoint files (the plan's UART lane folded into the logging lane), a
follow-up driver lane and a twin-test agent; the lead merged them and fixed the cross-lane reds.
