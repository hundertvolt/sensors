# U21 close scan (silent_failure_scan.md), 2026-10-08

Unit U21: the toolchain installer, the build overrides, the test and build scripts and the docs that describe them.
Every installer subprocess is bounded by one of three budgets, streams its output line by line and never echoes a
secret; every network step is retried; `versions.toml` is read as a typed table; one lock per toolchain directory and a
`toolchain-record.json` written last; apt runs as a bounded `update`, a retried `--download-only` and an install from
the cache (OF-57's apt half). The overrides resolve and screen every path, prove `unix_kbd_intr` in every Unix binary,
patch `modlwip.c` into every rp2 image (`modlwip_eagain`, proven post-build) and add a test-only tick offset a release
build refuses. A third Unix binary, `build-lwip`, runs the patched modlwip over loopback lwIP, and a seven-test hammer
(`tests/lwip_host/`) proves the EAGAIN send path against a control build. `scripts/test.sh` treats a missing record as
a missing build and runs the lwIP files last on `build-lwip`; `build_firmware.py` takes the lock and needs the record;
`typecheck.sh` records the stub version; the generator writes through rename (OF-41). Three code lanes (T, O, S) and two
docs lanes (D, E) on disjoint files; the lead merged the WIP bases, built the base toolchain three times, upgraded the
shared toolchain once alone (A-21) and handled one incident.
