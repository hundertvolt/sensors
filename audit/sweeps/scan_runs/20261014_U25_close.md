# U25 close scan (silent_failure_scan.md), 2026-10-14

Unit U25: the digital twin. Its fakes follow the rp2 port where the port's source decides: a Timer on the 16-alarm pool with
rp2's soft and hard callback rules, one static object per peripheral id, the UART's register model with its FE and BE bits,
WLAN singletons with cyw43's access-point layout on the loopback, a wall clock answering rp2's 8-field time tuple, and the
flash-write stall a config flush costs the loop. The chip fakes follow their datasheets (power cycle, keyed fresh faults, the
faults the port cannot raise refused, atomic state saves and a line on a bad state file). The runner takes a wiring plan,
exits 3, 4 or 5 on a reset or a power loss with the kept registers, serves a local NTP responder and refuses every public UDP
destination. Every twin test file boots its device from the generated plan; the in-process tier runs per device; the HTTP
scenarios moved to a host-side harness that shares one boot between idle-checked scenarios; the CI suite archives its state per
pass, completes its fault matrix and adds Runs 12 and 13; CI runs one twin job per device, GC stage and part. Lanes MN, C, R,
P (wave 1, one API merge), SH and G (wave 2), the lead's fixes on each merged tree and the lead step, lane E (boot sharing, the
per-stage CI job), then lane D (docs), on disjoint files; `src/` was not edited.
