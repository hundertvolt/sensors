# U24 close scan (silent_failure_scan.md), 2026-10-14

Unit U24: the test rig. Every MicroPython test file runs on one shared async harness (`tests/_async_harness.py`) that
ends every task a call created, names any it could not end and keeps no finished one; microtest runs sorted names,
checks each test's value, prints an ABORT line with the traceback for a test an interrupt or exit ended, and runs
registered after-each hooks with a parked-task check. The fakes follow the rp2 port where its source decides (I2C, SPI,
UART pin rule, WLAN, Timer), cite their port facts and fail a real poll over a fake. Constants are read from `src/` or
pinned with their source; response bodies go through a strict, now linear, JSON recogniser. The per-file timeout's
first signal is SIGINT, so a hang names its test; an aborted run stops every background job before it releases the
port lock. The build chain's tests read typed TOML fixtures, every per-device loop has a non-empty floor, and the
generator removes a removed device's modules, which `require_fresh()` now refuses. Lanes H, F, J, T, S (wave 1), U1-U4
and D (wave 2), then K, M, B and one docs lane, on disjoint files; the lead merged, fixed what the merge made red, and
shrank the allow-lists.
