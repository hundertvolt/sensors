# U11 close scan (silent_failure_scan.md), 2026-10-07

Unit U11: the core. The config store writes an absent file once, serves an unreadable one from defaults without writing it,
repairs a damaged one, refuses writes once closed and marks a failed write `unpersisted`; one module's PUTs run one at a
time under `_set_lock`, staged then pushed then written. Every error source's reset answers bool and `ResetErrors` resets
them concurrently, answering per field. The log level is refused, never clamped. The system service owns one reset path
(record, flush, pause, arm), measures uptime, ends a storage pause by a deadline and runs the supervisor as its own task
that escalates at the first end past the budget. Four lanes on disjoint files; the lead merged them, fixed what only the
merged tree showed and ran the whole gate.
