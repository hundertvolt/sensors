# U26 close scan (silent_failure_scan.md), 2026-10-14

Unit U26: the real-hardware levels, L3 (the flash tier) and L4 (the bench tier) of `tests_hardware/`. Device scripts report facts
over the bench board's own wiring (`BENCH`, rendered from `tests_hardware/bench_facts.py`'s build of the `bench = true` device's
TOML, with shared includes, an armed watchdog fed in bounded steps and scratch config for every build) and host tests judge
them. A session saves the evidence first (the verbatim `GET /status` and the raw FRAM), holds the standard board state at start
and end, checks the image record and finds the board's address; one marker table is registered by both pytest tiers under
`--strict-markers`, and the wear gates deselect. L0 guards read every device script and module (facts, bench facts, watchdog,
rig parking, GC stage, config flush, FRAM regions, clones, product copies, task ends, wear). `TwinBoard` runs any script in the
digital twin, and the twin record holds each instrument's twin result with its reason. The manual mode states each persisting
step before its confirmation. Lanes A and B (wave 1, one API stop), D1, D2 and E (wave 2), the lead's steps at both merges, then
lane X (docs), on disjoint files, with the two U25 CI fixes merged in; `src/` was not edited (`git diff dd4a94b 60305bc -- src`
empty), and nothing ran on hardware. Since U25's pushed head `dd4a94b`, before these records: 257 files, 90 added, 6 deleted.
