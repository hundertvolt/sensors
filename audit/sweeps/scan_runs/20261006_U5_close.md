# U5 close scan (silent_failure_scan.md), 2026-10-06

Unit U5: config objects and `max-args = 8`. One logging config object (`LogConfig`, `DEFAULT_LOG`,
`make_logger(log, name)`) replaces every `fram=`/`history_length=`/`debug=` triple; `WebserverService` takes
`RouteSources`/`ServingLimits`/`StaticSite`; `WifiConfig`, `NtpTiming`, `ValueRef`, `SgpBackup` and
`ResponderCallbacks` carry the other over-8 groups; signals, the WiFi LED and the level-setters provider are passed at
construction (no `register()`/`finalize()`, `set_ext_led()` or `set_level_setters()`); every config object is a runtime
`namedtuple` typed through a `NamedTuple` shadow under `TYPE_CHECKING`; ruff's `max-args` is 8 and ESLint's ceilings
are pinned by tests.
