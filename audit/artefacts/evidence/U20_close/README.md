# U20 close evidence

Each folder holds a lane's working logs and probes, or the lead's (paths inside name the scratch worktrees they ran in;
files over 100 KB gzipped). Lanes S, D and E left no report, so `commits.txt` in their folders is their commit log with
file stats. Product source was left out. Tree exports, scratch copies of source, tests and TOMLs, overlays, planted
mutants and generated modules were never copied. Of the files picked, 39 more were refused by the checks against the
tracked tree: 8 by blob, 2 by name and 29 by content (90% or more of their lines in one tracked file). The lead put 22 of
the content matches back: each matched only an earlier unit's tracked log of the same test file (the same pass list),
never product source, and they hold this unit's figures. `EXCLUDED.txt` lists each refused file with its
match, then what was left out as bulk, then the credential grep. Two diffs were made at assembly in place of generated
copies: `lane_g/defs_base_vs_new.diff.txt` and `lead_int/k_patch/gen_before_vs_after.diff.txt`.
