**Scanner blind spot (not changed): shapes it misses**
1. A value passed positionally into a call that waits inside it: `runner._serve_until(0.2, …)`, `runner._test_loop_lag(5, …)`, `scenario(_PAST_CANCEL_ACK_HOLD_MS)`. The scanner knows `run_timed` but not `run(coro, bound)`.
2. An assignment to an attribute the code under test waits on: `runner._LOOP_LAG_REPORT_MS = 20`.
3. Timer periods: `Timer(period=…)` and `.init(period=…)`; `period` is not in its keyword set.
4. A loop count that bounds a poll: `for _ in range(100): … sleep_ms(…)`.
5. Wait keywords with other names: `poll_ms=`, `poll_tries=`, `start_timeout_ms=`.
6. A constant that reaches a wait through arithmetic or a call: `_WAIT_TIMEOUT_MS = int(_WAIT_TIMEOUT_S * 1000)` used as a `range()` count.
