## 6 Gaps

- **G1 Device TOML schema is one checked contract (P12).** The TOML key set is a public interface (OR24.a (2)) and P12 lists it, but its normative text (SPEC L.3), the owner-kept `buildspec.py` table and `validate.py` are tied by nothing: no `tests_scripts` test reads L.3 (grep of `tests_scripts/`: L.3 appears only in comments). Proposed: SPEC L.3's key list is generated from, or checked against, `buildspec.py`, and a key change updates every consumer in one commit.
- **G2 Shell scripts share one safety convention (P4).** `shellcheck` is the only shell gate; `set` flags, traps and temp-file cleanup vary by script (SCR.T08, SCR.S08 unquoted loop, TOOL.S04 temp leak; G8.077's one-trap pattern exists in `test.sh` only). G10's conventions cover `src/` only.
- **G3 The frozen image is reproducible from its inputs (P11).** 3.3 made the frozen website byte-reproducible; the rest of what ships — generated modules, `ast.unparse`d stripped copies (host-CPython-dependent, SCR.T09), wiring plans — has no such rule (GEN.T11, SCR.T11). Proposed: same commit, pinned toolchain and pinned host CPython give byte-identical frozen inputs (build date excepted) across hash seeds; the host Python for `ast.unparse` is pinned or the output proven invariant. Extends an OR2.c decision; not an owner question.
