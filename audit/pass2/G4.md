### G4/R55 UART code never blocks the asyncio loop
- **Req**: `asy_uart_driver.py` and `asy_uart_comm.py` never hold the asyncio loop, not even in a wait: rp2 `UART.read()/readinto()` wait out `timeout_char` per missing byte inside `mp_event_handle_nowait()`, which never yields, while `POLLIN` fires on one byte.
